IncoWen Mono Web Fonts

IncoWen Mono is a monospaced font family with Inconsolata Latin glyphs and LXGW WenKai Mono Lite Chinese glyphs.

Regular: The quick brown fox jumps over 1234567890. 中文示例。

Bold: The quick brown fox jumps over 1234567890. 中文示例。

Use the stylesheet

Add this to an HTML document:

<link rel="stylesheet" href="https://hanlhe.github.io/IncoWen-Mono/IncoWenMono.css">

Then set font-family: "IncoWen Mono", monospace; in CSS. Use font-weight: 700 for Bold.
